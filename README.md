# Yuvaan Pandey — Developer Portfolio

A responsive personal landing page for Yuvaan Pandey, built with semantic HTML and CSS. The page highlights development services and makes it easy to get in touch.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create a GitHub repository and push this project to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. When the deployment finishes, GitHub will show the published site URL in the Pages settings.

All image and stylesheet paths are relative so the page also works when served from a GitHub Pages project subpath.
